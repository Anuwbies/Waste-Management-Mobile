QUESTION 1: What is a bottleneck in a system?
ANSWER: A bottleneck is a specific component or stage in a system that limits the overall performance or throughput because its capacity is lower than the other parts of the system, causing delays.

QUESTION 2: Name one optimization technique to reduce load time.
ANSWER: Caching is an effective technique where frequently accessed data is stored in a fast-access layer (like Redis or local memory) to avoid repeated expensive computations or network requests.

QUESTION 3: What does "horizontal scaling" mean?
ANSWER: Horizontal scaling means adding more nodes or instances (like more servers) to a system to handle increased load, rather than increasing the power (CPU/RAM) of a single server (which is vertical scaling).

QUESTION 4: Why is it important to store API keys securely?
ANSWER: Secure storage prevents unauthorized access to services, protects sensitive data, and ensures that malicious actors cannot incur costs or bypass security controls using your identity.
